# 📱 App de Login e Cadastro

Aplicativo mobile desenvolvido em **React Native** com **JavaScript** e **TypeScript**, contendo **login e cadastro funcionais** integrados a um **banco de dados**.

### 🚀 Tecnologias
- React Native  
- TypeScript / JavaScript  
- Banco de Dados  
- Expo  

### ⚙️ Funcionalidades
- Login e cadastro de usuários  
- Integração com banco de dados  
- Interface moderna e responsiva
